                   from Home Assistant. FX publishes the same fields and topics as the single phase Radian inverter,
                   plus the daily buy/sell/output/charger kWh counters that only the FX block provides.
                 - new: FX values are scaled using the scale factor registers reported by the block itself
                 - add: scan now logs the SunSpec blocks it found and warns when no inverter block was decoded,
                   instead of skipping unsupported hardware in silence
                 - add: FX error and warning bitfields report every flag that is set, not just single bit values

1.2.0_20260804   - fix: the summary assumed FNDC shunt C was always a diversion load, so diverted_current and
                   diverted_power reported nonsense on any system using shunt C for something else
                 - new: configurable shunt roles in config.cfg [Labels] - solar, charger, inverter, load,
                   diverter, unused, other. Summary publishes shunt_<role>_current and shunt_<role>_power for
                   each role in use. Leaving the roles blank keeps the previous behaviour
                 - fix: configured shunt labels are now used for the Home Assistant sensor display names,
                   instead of being written only to the JSON file. Entity ids and topics are unchanged
                 - add: shunts declared unused are excluded from the calculated battery current
                 - add: shunt roles reported in the JSON as shunt_a_role, shunt_b_role, shunt_c_role
